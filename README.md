# Project Metasequoia

重み行列を持たず、**正弦の模様の干渉と回折だけ**で分類する学習器 SinWave を、画像認識（2 次元）へ広げ、
継続学習の「分類の木」、さらに複数人で育てる分散学習の規格へ進めるための研究リポジトリ。
前のプロジェクト [Sin-CNN2](https://github.com/devaf09/Sin-CNN2)（1 次元、文字列の分類）の後継。

## しくみ（光の実験装置に例えると）

```
画像（透過マスク）→ [Sin の板 → 回折] × 16 → レンズ（2 次元 FFT）→ 出力面の 10 個の窓の明るさ → クラス
```

- **Sin の板**: 画面を区画に分け、区画ごとに A·sin(ωx·x + ωy·y + φ) で光の位相をずらす板。学習するのは振幅 A と初期位相 φ だけ（ω は乱数で固定）。
- **回折**: 光が少し進んで広がる効果（角スペクトル法という標準的な計算）。
- 学習するパラメータは 2,000〜8,000 個程度。

## 現在の成績（段階 A、テスト正解率、10000 steps、3 seed の平均±標準誤差）

| モデル | params | MNIST | Fashion-MNIST |

詳細と失敗した試みは [NOTES.md](NOTES.md)、計画は [docs/plan_stage_A.md](docs/plan_stage_A.md)。

## 長所
- パラメータが少ない（区画ごとの 2 数だけ）。Fashion-MNIST では同程度の大きさの小さな CNN を上回る。
- 構造が単純で、光学素子（位相板とレンズ）として実装できる形をしている。
- 1 次元版では、別々に学習した技能を「明るさを足すだけ」で融合・取り消しできた（段階 B で 2 次元でも確かめる予定）。

## 短所
- MNIST では小さな CNN に負ける。
- 計算が重い: FFT を層の数だけ行うため、同程度の CNN より 1 step あたり約 10〜20 倍遅い。
- 1 次元で効いた「干渉を減らす照明」やホログラムの参照波は、2 次元では効かなかった。

## 向いている使い方
- 継続学習・モジュール性（技能の追加・取り消し・足し算）の研究。精度競争には向かない。
- 光学ニューラルネット（回折型 NN）の、少ないパラメータでの基準として。

## 使い方

```bash
python experiments/a1_sinwave.py --data fashion --seeds 0 --N 32 --scale 1 --patches 16 --steps 10000
```

- データ（MNIST / Fashion-MNIST）は `data/` に置く（リポジトリには含めない）。
- 必要なもの: Python 3、PyTorch、torchvision。テストは `python -m pytest tests`。
- `sinwave_minimal.py` は前のプロジェクトの 1 次元版（v1.3.0）をそのまま取り込んだもの。`sinwave2d_minimal.py` は 2 次元版（v0.1.0）。
