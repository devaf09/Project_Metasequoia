# 段階 A の実験計画（案）: SinWave を 2 次元にして画像を認識する

2026-10-14 作成。まだ実験は始めていない。データの取得許可待ち。

## 1. 前のプロジェクト（Sin-CNN2）から引き継ぐこと

- 構成: 入力の光 → [Sin の板（区画ごとの A·sin(ωt+φ) の位相変調）→ 回折（角スペクトル法）→ 明るさを 1 に戻す] × 16 → レンズ（FFT）→ 窓の明るさ + 背景光 → クラス。学習するのは A, φ, 温度, 背景光。ω は固定でよい。
- 大きく効いたのは、どれも「異なる位置どうしの干渉（強度 = 振幅の 2 乗の交差項）を減らす」工夫だった（tilt/アダマール照明、平均の滲み層）。2 次元でもここが一番の論点になると見ている。
- 1 次元で効いた「文字 = 角速度」の符号化は画像には無い。画像は透過マスクとして当てるので、遠方場は画像のフーリエ変換になり、位置不変の性質も失われる。1 次元の工夫がそのまま効く保証はない。
- 典型の模様（クラス平均との相関）での判定は窓より良く、学習していないランダムな板でも 70% 出た（リザバー的）。2 次元でも基準として必ず測る。
- 効かなかったもの（繰り返さない）: 出力面全体を周波数として読む、層間距離の変更、出力の帰還、広い出力面、対数・差動検出、層ごとのレンズ、前処理光、std の滲み、入力の FT、ω の特殊な初期配置、Kerr 風の非線形、振幅変調、背景抑制、本物の時間振動、レイヤ全体で 1 組の (A,ω,φ)。

## 3. 比較相手（すべて同じ前処理・同じ分割、3 seed）

| 名前 | 中身 | パラメータ数 |
|---|---|---|
| ロジスティック回帰 | 画素 784 → 10 | 7,850 |
| 典型との照合 | 画素のクラス平均との相関 / 最近傍の平均 | 学習なし（典型 7,840 個を保存） |
| 小さな CNN | SinWave と同程度（約 2k と約 8k の 2 段階） | 2k / 8k |
| 小さな MLP | 同上（784 入力なので 2k では隠れ層 2〜3 個しか置けない。不利なのは明記する） | 2k / 8k |
| ランダムな板 + 典型との照合 | 学習しない SinWave（干渉と回折そのものの力） | 0 |
| 参考（既存研究） | 回折型ニューラルネット D2NN（Lin ら 2018）。画素ごとに位相を学習する光学 NN。数値は文献で確認してから載せる | 数十万 |

SinWave の位置づけは「画素ごとの位相を学習する D2NN に対し、区画ごとの (A, φ) だけで 2 桁少ないパラメータ」。精度で CNN に勝つことは目指さない（段階 B の継続学習が本題）。

## 4. 指標

- テスト正解率（3 seed の平均 ± 標準誤差）。技能を分けた場合は task / class も。
- 学習するパラメータ数、保存サイズ。
- 計算量: 1,000 枚の推論時間、1 step の学習時間、ピークの GPU メモリ（`torch.cuda.max_memory_allocated`）。CPU の推論時間も参考に。

## 5. 最初に試す構成（A0）

- 場 64×64。画像 28×28 を 2 倍に拡大して 56×56 にし、中央に置く（周りは暗く、回折で広がる余地）。振幅マスク（明るい画素ほど光を通す）。
- Sin の板: 16 枚、区画 8×8 = 64 個。区画ごとに `A·sin(ωx·x + ωy·y + φ)`（2 次元の縞。ω は向きと細かさを乱数で決めて固定）。学習するのは A, φ → 16×64×2 = 2,048 個 + 温度 + 背景光 10。
- 回折: 2 次元の角スペクトル法（周期境界）。最後に 2 次元 FFT のレンズ。
- 検出器: 出力面に 10 個の窓（例えば円周上に等間隔、3×3 画素）。並行して典型の模様での判定も出す。
- 学習: Adam、lr 0.01、余弦スケジュール、バッチ 256、まず 3,000 steps（約 13 エポック相当）。

## 6. 実験の順番

| 番号 | 内容 | 主な問い |
|---|---|---|
| A0 | 比較相手を全部測る（CPU 中心、すぐ終わる） | 基準の数字 |
| A1 | A0 構成で MNIST / Fashion を学習、ランダムな板 + 典型も | そもそも学習できるか |
| A2 | 入力の当て方: 振幅マスク / 位相マスク / 両方、拡大率、場の大きさ 64 / 128 | 一番素直な入力 |
| A3 | 干渉を減らす工夫の 2 次元版: (a) tilt 照明（入射角を変えた平面波 n 通り）、(b) ブロックごとのアダマール位相符号（部分的に非コヒーレント）、(c) 2 次元の平均の滲み層 | 1 次元の一番の教訓は 2 次元でも成り立つか |
| A4 | 層数 (4/8/16/32)、区画数 (4×4〜16×16)、ω 固定 vs 学習、背景光あり/なし | 容量とパラメータ数の兼ね合い |
| A5 | 読み出し: 窓 / 典型の模様 / 両方 | 2 次元でも典型が窓に勝つか |
| A6 | 良い構成を 3 seed、計算量の測定、省メモリ実行（照明パターンを 1 つずつ足す・勾配チェックポイント・バッチ分割）と精度が一致するかの確認 | 最終の表 |
| A7 | 2 技能に分けた並列光路の融合（0〜4 と 5〜9）を軽く試す | 段階 B への橋渡し |

- 注目点: 照明パターンを完全に非コヒーレントにすると、出力は画素の明るさの線形和になり、ロジスティック回帰と同じ種類のモデルに近づく。コヒーレント（干渉あり）は画素の 2 乗の特徴を持てる。どちらに寄せるのが良いかは 1 次元と結論が変わるかもしれない。
- GPU（RTX 3060 12GB）は 1 つずつ順番に回す。64×64 の場・バッチ 256・16 層なら、照明なしで 1 GB 未満、照明 8 通りでも数 GB の見込み（A1 で実測する）。
